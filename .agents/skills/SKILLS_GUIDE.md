# 🛠 Справочник скиллов Matt Pocock (Skills Guide)

Данный документ содержит полный список всех скиллов (команд и сценариев) из репозитория `mattpocock/skills`, их описание на русском языке и примеры того, как вызывать их в чате с **Gemini / Antigravity IDE**.

---

## 💡 Как активировать любой скилл в чате

Вы можете активировать любой скилл, просто написав его название или попросив выполнить описанный сценарий.

**Примеры:**
* *"Выполни `grill-with-docs` для фичи авторизации"*
* *"Давай напишем эту функцию по `tdd`"*
* *"Сделай `code-review` последних изменений"*
* *"Проведи `diagnosing-bugs` для ошибки с загрузкой списка"*

## 1. ⚙️ Инженерия и разработка (Engineering)

Эти скиллы используются для повседневного написания кода, проектирования и отладки.

### 🔹 Планирование и Архитектура
| Команда / Скилл | Описание |
| :--- | :--- |
| **`ask-matt`** | Интерактивный роутер-ассистент: помогает определить, какой скилл или сценарий лучше всего подходит под вашу текущую задачу. |
| **`grill-with-docs`** | Режим строгой «допрос-сессии» (интервью) по архитектуре и требованиям фичи с параллельным обновлением проектной документации (`CONTEXT.md` и ADR). |
| **`domain-modeling`** | Направленное проектирование предметной области: уточнение терминов, проверка сценариев использования и фиксация доменного языка (Ubiquitous Language). |
| **`codebase-design`** | Свод правил для проектирования «глубоких модулей» (Deep Modules) с узким публичным интерфейсом и хорошей изолированностью. |
| **`improve-codebase-architecture`** | Сканирование проекта на предмет архитектурных слабостей, генерация визуального отчета и проведения интервью по выбранным проблемам. |
| **`setup-matt-pocock-skills`** | Однократный скрипт первичной настройки репозитория (структура доменных документов, баг-трекер, метки). |

### 🔹 Написание Кода и Тестирование
| Команда / Скилл | Описание |
| :--- | :--- |
| **`tdd`** | Разработка через тестирование (Red-Green-Refactor loop). Написание тестов на публичных границах (Seams) до написания кода, по принципу «один вертикальный срез за раз». |
| **`implement`** | Полный цикл реализации фичи или тикета: от планирования швов (seams) и запуска `tdd` до финального `code-review` перед коммитом. |
| **`prototype`** | Создание быстрого «одноразового» прототипа (CLI-скрипта или вариантов UI) для проверки гипотезы или архитектурной идеи. |
| **`code-review`** | Параллельный аудит кода по двум осям: **Стандарты** (чистота кода и запахи по Фаулеру) и **Спецификация** (соответствие исходному ТЗ). |
| **`diagnosing-bugs`** | Строгий системный цикл поиска сложных багов: воспроизведение → минимизация → гипотеза → инструментация → исправление → регрессионный тест. |
| **`resolving-merge-conflicts`** | Пошаговое решение git-конфликтов при слиянии/ребейзе блок за блоком на основе целей обеих веток (без аварийной отмены `--abort`). |

### 🔹 Трекинг задач и исследование
| Команда / Скилл | Описание |
| :--- | :--- |
| **`research`** | Запуск автономного исследования по вопросу с анализом авторитетных источников и созданием итогового Markdown-файла с цитатами. |
| **`to-spec`** | Превращение текущего диалога или идеи в готовую техническую спецификацию (Spec) для трекера задач. |
| **`to-tickets`** | Разбиение спецификации или плана на цепочку связанных атомарных задач (tracer bullets) с зависимостями. |
| **`triage`** | Управление статусами и первичный разбор (сортировка) поступивших багов и задач. |
| **`wayfinder`** | Составление «карты решений» для гигантских проектов (превышающих размер одного контекстного окна) в виде связанных задач-решений. |

## 2. 🚀 Продуктивность и процессы (Productivity)

Скиллы для управления ходом мыслей, обучения и передачи контекста.

| Команда / Скилл | Описание |
| :--- | :--- |
| **`grill-me`** | Строгий допрос пользователя по идее или плану до тех пор, пока все ветки дерева решений не будут четко определены. |
| **`grilling`** | Фоновый механизм интервьюирования по любым неконкретным требованиям или спорным моментам. |
| **`handoff`** | Сжатие текущей сессии диалога в итоговый документ передачи (Handoff summary), чтобы другой агент или новая сессия продолжила работу без потери контекста. |
| **`teach`** | Интерактивный режим обучения пользователя новым навыкам или концепциям с сохранением прогресса в текущей папке. |
| **`writing-great-skills`** | Справочное руководство по созданию собственных предсказуемых и эффективных скиллов для AI. |

## 3. 🛠 Вспомогательные утилиты (Misc)

Утилиты для защиты гита и настройки рабочего окружения.

| Команда / Скилл | Описание |
| :--- | :--- |
| **`git-guardrails-claude-code`** | Установка перехватчиков (hooks), блокирующих опасные команды git (например, `push --force`, `reset --hard`, `clean -fd`). |
| **`setup-pre-commit`** | Быстрая настройка Husky, Prettier, линтеров и автоматических тестов перед коммитом. |
| **`migrate-to-shoehorn`** | Автоматическая миграция тестов на безопасное приведение типов `@total-typescript/shoehorn`. |
| **`scaffold-exercises`** | Генератор учебных репозиториев и упражнений с тестами и решениями. |

## 📌 Памятка по вызову

Чтобы применить любой скилл, просто укажите его имя в нашем разговоре, например:

> **Вам:** *«Gemini, давай запустим `grill-with-docs` для структуры нового экрана»*
> 
> **Вам:** *«Напиши юнит-тесты и реализацию модуля авторизации по `tdd`»*
> 
> **Вам:** *«Сделай `code-review` изменений»*
